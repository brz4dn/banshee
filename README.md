**Banshee Toolkit**

Banshee is a tool that makes unenrolls the School Chromebook

**Features**

Interactive UI: Custom shell layout with *dynamic status display.*

Automated Package Installation: Installs ***core** libraries.*

Unenrollment Process: Uses **ManualEscape** to *unenroll the school device.*

CrossPlatform: *Compatible with* Linux, macOS, and Windows operating systems.


Prerequisites

Python 3.8+ must be installed on your system.pip package manager.
